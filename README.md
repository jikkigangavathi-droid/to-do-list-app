# To-Do List App

A beginner-friendly student project built with HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all completed tasks
- Automatically save tasks in browser local storage
- Responsive layout for mobile and desktop

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — task functionality and local storage

## Run locally
Open `index.html` in your web browser.

## Publish with GitHub Pages
1. Upload all project files to your GitHub repository.
2. Open **Settings → Pages**.
3. Under build and deployment, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site.

## Technologies
HTML5, CSS3, JavaScript
